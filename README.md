# まいにち献立

個人用の献立・買い物リスト管理アプリのGitHub Pages版（初期移植）。

## 開く
GitHub Pages: リポジトリの Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。

## 現時点の実装
- 週間献立、料理ごとの評価と登録候補からの差し替え
- 人数、朝の汁物、週のパスタ回数などの設定
- 好き嫌い・アレルギー条件の追加、編集、削除
- 買い物リストの集計、在庫の差引
- ChatGPTとの手動コピー・貼り付け連携
- データのJSON書き出し・読み込み

## 注意
これは保存されていた**初期版HTML**をもとにした移植であり、以前のSites版 v4.1と同等ではありません。Sites版に存在した64品レシピ、食品成分表による栄養計算、栄養チェックの献立画面統合、献立リセット等はこれから再実装する必要があります。栄養の推測値を出すことはしません。

GitHub Pagesは公開Webサイトです。初期の好き嫌い設定は個人情報を避けるため空にしてあります。評価・設定はアクセスしたブラウザのlocalStorageに保存します（同期なし）。GitHub上に個人のアレルギー・好き嫌い・APIキーや食事記録をコミットしないでください。
