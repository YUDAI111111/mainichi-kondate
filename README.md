# まいにち献立

個人用の献立・買い物リスト管理アプリのGitHub Pages版（初期移植）。

## 開く
GitHub Pages: リポジトリの Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。

## 現時点の実装
- 週間献立、料理ごとの評価と登録候補からの差し替え
- **献立リセット**：1週間分の献立を新しく組み直し、評価も初期化（人数・好き嫌い・在庫は維持）
- **評価だけリセット**：献立を変更せず評価履歴のみ初期化
- **献立の種類**：通常（主菜・副菜・汁物、同系統）／パスタ（単品、汁物任意、副菜なし）／鍋（主菜と汁物を兼用、副菜任意）／カレー（単品、副菜任意）
- **カレー・鍋のレパートリー拡充**：各13品（従来各1品から12品ずつ追加）。全24品にアプリ用の材料・分量・調理手順を登録
- **週間献立に料理家名を表示**：原典を参考にした料理は「参考：料理家名」を料理名の下に表示。家庭料理の登録例に料理家名は付けない
- **献立リセット**：パスタ指定回数を保ち、鍋・カレーを含めて料理構成を守って再生成
- **弁当不要の曜日を設定**：初期値は土日。設定画面で7曜日を変更でき、画面表示・買い物量・弁当の未登録警告を連動
- **弁当と買い物**：翌日に弁当が必要な場合に限り、通常献立の主菜と副菜を夕食＋翌日分の計2食分用意。カレー・鍋・パスタの翌日は弁当を別途準備として警告
- 料理レパートリー104品（主菜・副菜・汁物・鍋・カレー）、種類・系統・参考元・名前検索、献立への選択
- **全104品の材料・分量・調理手順**を recipe-details.js で共有管理。recipe.html で人数を変更して別タブ表示
- 週間献立・レシピ一覧のどちらからもレシピ詳細を別タブで表示
- 16品分の出典料理名・料理家・調整内容を登録。13品の参考元URLを確認済み（残る3品は直接リンク未確認）
- 人数、朝の汁物、週のパスタ回数などの設定
- 朝食の詳細設定（納豆・目玉焼きの数、温めたご飯と炊飯後重量、ウインナーの有無、調理油、追加食材）
- 朝食設定を週間表示と買い物リストへ反映。主食は炊飯後重量で管理し、買い物リストでは生米に約2.2倍換算で変換（概算）
- **週間UIの見やすさ改善**：月曜から日曜まで横長の7行で縦に配置。各行で曜日・朝食・弁当・夕食・1日の食費を横並び表示し、画面が狭い場合は折り返し
- 好き嫌い・アレルギー条件の追加、編集、削除
- 買い物リストの集計、在庫の差引
- **献立画面の手動栄養計算**：『栄養計算（現在のレシピで集計）』を押して7日分を集計。自動更新せず、変更後は再計算を要求
- **曜日別の食費**：各日に食べる1人分の献立・前夜からの弁当取り分けを重複なしで集計。食費は設定人数で合計
- **週予算との比較**：設定画面の予算を週単位に変更。食材購入見込み額は買い物リスト・在庫・単価から算出。未登録の料理や食材は比較を暫定値と表示
- **食材価格マスター**：現在のレシピに必要な食材の仮単価を設定画面から編集可能。`food-estimates.js` の仮栄養参考値・仮価格を使い、編集単価を優先
- **ビタミン・ミネラル集計**：既存の栄養チェックタブに15項目（A・D・E・K・B1・B2・B6・B12・C・葉酸・Ca・Fe・Zn・Mg・K）を追加。曜日別／1日平均を選択可能
- **成分表の参照**：96食材を文部科学省「日本食品標準成分表2020年版（八訂）」の食品番号に対応。元の食品名・食品番号をタブ内で確認可能。生・調理状態が一致しない代用を含み、2023増補や2026正誤は未照合
- **食事別計上**：朝食・弁当・夕食の成分と金額を別々に算出。通常献立は夕食1食分、翌日弁当1食分へ配賦。土日弁当なし、未登録弁当・パスタは「未算出」
- **基礎栄養素**：熱量・たんぱく質・脂質・炭水化物・食物繊維・食塩相当量は従来の仮参考値。公的データとの照合は未完了
- ChatGPTとの手動コピー・貼り付け連携
- データのJSON書き出し・読み込み

## 注意
これは保存されていた**初期版HTML**をもとにした移植であり、以前のSites版 v4.1と同等ではありません。献立レシピの自由編集や調理損失を加味した栄養計算は未対応です。マクロ栄養素は独自の仮参考値、ビタミン・ミネラルは食品番号を照合した2020年版の成分値を使用しています。料理の材料と成分表の食品が完全には一致せず、計算値は参考用です。 食材の仮単価も実際のスーパー販売価格ではありません。料理の一覧104品の材料・手順はアプリ独自の参考例で、料理家の原典とは同一ではありません。

GitHub Pagesは公開Webサイトです。初期の好き嫌い設定は個人情報を避けるため空にしてあります。評価・設定はアクセスしたブラウザのlocalStorageに保存します（同期なし）。GitHub上に個人のアレルギー・好き嫌い・APIキーや食事記録をコミットしないでください。
## 微量栄養素の出典

- CSV変換元（CC BY 4.0）：https://github.com/katoharu432/standards-tables-of-food-composition-in-japan
- 現在の成分マッピングファイル：`micro-food-data.js`。商品・加熱後の実測値ではなく、食品成分表の標準値から計算します。
